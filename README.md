### Tools I built at work, rewritten generic and published here

**[agent-log-analyzer](https://github.com/GuillemCortesOvide/agent-log-analyzer)**
Matches agent logs against a YAML catalogue of failure signatures and explains
each finding in plain language, so first pass triage no longer means reading
raw logs. The catalogue is data, not code, so it grows without a release.

**[log-archive-explorer](https://github.com/GuillemCortesOvide/log-archive-explorer)**
Streams events straight out of nested tar and zip archives up to three levels
deep without ever unpacking to disk. Turns hours of manual error hunting inside
multi gigabyte exports into a filtered report.

**[cold-storage-retrieval-runner](https://github.com/GuillemCortesOvide/cold-storage-retrieval-runner)**
Bulk cold storage restores that survive the transient failures those jobs are
full of: retry with backoff, live progress per tenant, and it wraps whatever
restore command you already have.
